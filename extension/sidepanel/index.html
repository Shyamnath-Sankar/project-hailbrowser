HailBrowser

What should I do in this tab?

HailBrowser drives your real browser with the model you choose. Use Ultrafast for forms and searches, Normal for anything open-ended.

Settings
Saved
Normal agent

A tool-calling agent: reads the page, clicks, types, takes screenshots. Works with any provider.

⚡ Ultrafast agent

One decision request per step: the page becomes a numbered element table and a decision model picks an operation and a target. No screenshots.

A small classifier (e.g. together/Tev1-4B-experimental) answers one letter per question. The operation and target questions run in parallel, so each step is one round trip.

Pick a fast model (Groq, Gemini Flash, Haiku). It also writes field text, so typing costs no extra call.

API keys

Stored only in this browser (chrome.storage.local) and sent only to the provider you call.
